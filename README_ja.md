# CANkoro - CAN/CAN-FD 解析ツール

Vector VN1630/VN1640インターフェース対応の高性能CAN/CAN-FD解析アプリケーションです。Rustで構築されています。

## 機能一覧

### CAN通信
- Vector XL Driver Libraryを使用した **CAN / CAN-FD** 送受信
- **VN1630、VN1640、Virtual CAN** およびその他Vector対応インターフェースをサポート
- マルチチャンネル対応（接続インターフェースの全チャンネル）
- CAN FDのビットレート・データビットレート設定

### シグナルグラフ解析
- DBCファイルに基づく物理値のリアルタイムプロット
- シグナルごとの**独立Y軸**、共通時間軸
- **カーソル解析** - 全シグナルを貫く縦線カーソルで補間値を表示
- **差異カーソル解析** - 2つのカーソル間の差分値（dV）、時間差（dt）、周波数を計算
- 速度調整可能な**ログファイル再生**モード
- 大量データの高速描画のためのデータ間引き

### CAN送信
- **転送モード** - 指定チャンネルでCAN受信 → 他の指定チャンネルへ即座に転送
- **変更転送** - シグナル値を変更して転送（物理値で指定、DBCのmin/max制限を遵守）
- **台形波** - 初期値から指定変化率でMAX値へ上昇 → MAX値を保持 → 指定変化率で初期値へ下降するシグナルパターンを生成。受信なしで独立送信可能
- 送信設定のJSON形式での保存/読込

### カスタム送信パネル
以下のウィジェットでユーザーが送信コントロールパネルを作成可能：
- **スイッチ** - ON/OFFでシグナルアクションを実行するトグル
- **数値ボックス** - シグナルにリンクした数値入力（DBCからmin/max取得）
- **セレクトボックス** - シグナル値にマッピングされたドロップダウン選択
- **ラベル** - テキスト表示

### ログ記録
- **ASC形式** - Vector標準ASCIIログフォーマット
- **BLF形式** - Vector標準バイナリログフォーマット（zlib圧縮対応）
- ID・チャンネルでフィルタ可能なリアルタイムCANログ表示

### 国際化
- **日本語**（デフォルト）と**英語**のUI
- 上部メニューバーからリアルタイムに言語切替可能

## 必要環境

### システム
- **OS**: Windows 10/11 (64-bit)
- **Vectorドライバー**: XL Driver Library（vxlapi64.dll）がインストール済みであること
- **ハードウェア**: Vector VN1630、VN1640、またはVirtual CANチャンネル

### ビルド
- Rust 1.75以降
- MSVCツールチェーン（Windowsビルド用）

## Vectorハードウェアのセットアップ

### 1. Vector Driver Setupのインストール

1. Vectorの公式サイトまたは付属CDから **Vector Driver Setup** をダウンロード・インストール
2. インストーラーの指示に従い、XL Driver Libraryをインストール
3. インストール後、`C:\Windows\System32\vxlapi64.dll` が存在することを確認

### 2. ハードウェアの接続

1. VN1630 / VN1640 をPCのUSBポートに接続
2. Windowsがデバイスを認識し、ドライバーが自動的にロードされるのを待つ
3. デバイスマネージャーで「Vector Hardware」配下にデバイスが表示されることを確認

### 3. Vector Hardware Config（推奨・任意）

> **注意**: CANkoroは起動時にドライバーから全チャンネルを自動検出するため、Hardware Configでの事前設定は必須ではありません。ただし、以下の設定を行うことでチャンネル割り当てがより確実になります。

1. スタートメニューから **Vector Hardware Config** を起動
2. 接続されたハードウェア（VN1630/VN1640）が一覧に表示されることを確認
3. （任意）アプリケーション登録:
   - **Application** セクションで **Add** をクリック
   - アプリケーション名に `CANkoro` と入力
   - 使用するチャンネル（Channel 1, Channel 2 等）を割り当て
   - **Bus Type** を `CAN` に設定
4. （任意）Virtual CANの設定:
   - Hardware Configの **Virtual Devices** タブで仮想チャンネルを追加可能
   - 物理ハードウェアなしでアプリのテストが可能

### 4. Virtual CAN（ハードウェアなしで使用する場合）

物理ハードウェアがなくても、VectorドライバーのVirtual CANチャンネルを使用してCANkoroの動作確認が可能です：

1. **Vector Hardware Config** を起動
2. **Virtual Devices** タブを開く
3. **Add** で仮想CANチャンネルを追加（2チャンネル以上推奨）
4. CANkoroを起動すると、チャンネル設定画面に `[Virtual]` と表示されるチャンネルが検出される
5. 転送テスト: Virtual Channel 1 → Virtual Channel 2 間で転送モードの動作確認が可能

### 接続の流れ（まとめ）

```
Vector Driver Setup インストール
        ↓
VN1630/VN1640 を USB接続（またはVirtual CAN設定）
        ↓
CANkoro 起動
        ↓
チャンネル設定タブ: チャンネルが自動検出される
  → [VN1630] Channel 1 (S/N: xxxxx, Ch: 0)
  → [VN1630] Channel 2 (S/N: xxxxx, Ch: 1)
  → [Virtual] Virtual Channel 1 ...
        ↓
使用するチャンネルにチェック → モード/ビットレート設定
        ↓
「接続」ボタンをクリック → CAN通信開始
```

## ビルド方法

```bash
# デバッグビルド
cargo build

# リリースビルド（最適化、LTO有効）
cargo build --release
```

リリースバイナリは `target/release/cankoro.exe` に生成されます。

> 注意: リリースモードではコンソールウィンドウが自動的に非表示になります（`windows_subsystem = "windows"`）。デバッグモードではログ出力のためコンソールが表示されます。

## 使い方

### 1. チャンネル設定
1. CANkoroを起動
2. **チャンネル設定**タブに移動
3. DBCファイルを選択（シグナル関連機能を使う場合は必須）
4. 使用するチャンネルを有効にし、ビットレート/モード（CANまたはCAN FD）を設定
5. **接続**をクリック

### 2. CANログの確認
- **CANログ**タブに切り替え
- IDフィルタで特定のメッセージID（16進数）を検索可能
- 自動スクロール、一時停止/再開を必要に応じて切替

### 3. シグナルグラフ
- **グラフ**タブに切り替え
- **シグナル選択**をクリックして表示するシグナルを選択
- **C1**チェックボックスでカーソル解析を有効化
- **差分**と**C2**で差異カーソル解析を有効化
- ログ再生：再生モードに切り替え、ログファイルを読込、再生ボタンを押す

### 4. CAN送信
- **送信設定**タブ：転送ルールと台形波パターンを設定
- **送信パネル**タブ：カスタムコントロールパネルでインタラクティブに送信
- **パネルエディタ**タブ：送信パネルの作成とカスタマイズ

## アーキテクチャ

```
┌─────────────────┐     crossbeam       ┌──────────────────┐
│  CAN受信スレッド   │ ──────────────────> │   メインスレッド     │
│  （チャンネル毎）   │      CanFrame       │   （egui GUI）     │
└─────────────────┘                     └──────────────────┘
                                               │
┌─────────────────┐     crossbeam       ┌──────────────────┐
│  CAN送信スレッド   │ <────────────────── │  ログライター       │
│ （転送/台形波）    │     TxCommand       │  （ASC/BLF）       │
└─────────────────┘                     └──────────────────┘
```

- **CAN受信スレッド**: `xlReceive`でブロッキング受信し、ロックフリーチャンネルでフレームを送信
- **CAN送信スレッド**: 転送と台形波生成を処理
- **メインスレッド**: egui GUI描画（60fps目標）
- **ログライター**: 非同期バッファ付きファイル書き込み
